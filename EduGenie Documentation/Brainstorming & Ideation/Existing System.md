# EduGenie – Existing System

## 1. Overview

In a conventional learning environment, students generally use different sources and tools for different learning requirements. A student may use one resource to search for answers, another resource to understand a difficult concept, another resource for practice questions, and additional resources for learning guidance.

## 2. Existing Learning Approach

The commonly used learning approach may involve:

- Searching for answers using online resources.
- Referring to textbooks and study materials.
- Watching educational videos.
- Using separate quiz or assessment platforms.
- Searching for summaries of lengthy content.
- Following learning resources independently without a personalized sequence.

## 3. Limitations Identified

The existing approach can create the following difficulties:

### 3.1 Multiple Resources

Students may need to switch between different resources for different learning activities.

### 3.2 Difficulty in Understanding Complex Topics

Some technical or academic topics may require simpler explanations suitable for the learner's knowledge level.

### 3.3 Lack of Integrated Practice

Learning and self-assessment may happen through separate platforms rather than through one integrated application.

### 3.4 Time Required for Revision

Long educational passages may take more time to revise when concise summaries are not readily available.

### 3.5 Lack of Structured Learning Guidance

Students exploring a new subject may not always know which concepts should be learned first and which topics should be studied next.

## 4. Need for Improvement

These limitations indicate the need for a unified educational assistant that can combine question answering, topic explanation, quiz generation, summarization, and learning recommendations within a single platform.
