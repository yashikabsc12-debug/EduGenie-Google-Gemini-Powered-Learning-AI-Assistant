# EduGenie – UI Design

## 1. Overview

The EduGenie user interface is designed as a simple web-based learning interface that allows users to select a learning task, provide input, submit the request, and view the generated response.

## 2. Main UI Components

The interface contains the following major components:

### 2.1 Application Header

Displays the EduGenie application name and learning assistant purpose.

### 2.2 Task Selection

The user can select the required learning task.

Available tasks include:

- Explain
- QnA
- Quiz
- Summary
- Recommend Path

### 2.3 Input Area

A text area is provided for entering questions, topics, or educational content.

### 2.4 Learning Level

The user can select the appropriate learning level when required.

Available levels include:

- Beginner
- Intermediate
- Advanced

### 2.5 Learning Goal

For the learning path feature, the user can provide a learning goal.

### 2.6 Submit Button

The submit button sends the user's request to the appropriate backend API.

### 2.7 Result Area

The generated AI response is displayed below the input section.
