# EduGenie – Project Presentation

## Slide 1 – Title

### EduGenie
### Google Gemini Powered Learning Assistant

AI-powered educational assistant for students.

---

## Slide 2 – Problem Statement

Students often require support for:

- Academic questions
- Complex topic explanations
- Practice quizzes
- Quick revision
- Learning guidance

Using separate resources for each activity can be time-consuming.

---

## Slide 3 – Proposed Solution

EduGenie provides multiple AI-powered learning features through a single web application.

The major features are:

- Q&A
- Explanation
- Quiz Generation
- Summarization
- Learning Path

---

## Slide 4 – Objectives

- Provide quick answers to learning questions.
- Simplify complex concepts.
- Generate practice quizzes.
- Summarize educational content.
- Provide personalized learning recommendations.
- Provide an easy-to-use learning interface.
