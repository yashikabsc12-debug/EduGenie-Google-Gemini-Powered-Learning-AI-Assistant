# EduGenie – Hardware Requirements

## 1. Hardware Requirements Overview

EduGenie is designed as a lightweight web-based AI learning application.

## 2. Minimum Hardware Requirements

- Computer or laptop
- Minimum 4 GB RAM
- Dual-core processor or above
- Minimum 5 GB available storage
- Keyboard and mouse
- Display monitor
- Internet connection

## 3. Recommended Hardware

- Computer or laptop with 8 GB RAM or above
- Modern multi-core processor
- Sufficient storage for the project and development tools
- Stable internet connection

## 4. Internet Requirement

An internet connection is required for communication with the Google Gemini AI service.

## 5. Hardware Requirement Summary

EduGenie does not require high-end hardware for the basic application interface and backend development. A standard computer with an internet connection is sufficient for running the project locally.
