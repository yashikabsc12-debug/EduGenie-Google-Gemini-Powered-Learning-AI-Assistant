# EduGenie – Technology Stack

## 1. Technology Stack Overview

EduGenie uses a combination of web development technologies, backend frameworks, AI services, and Python libraries.

## 2. Frontend Technologies

### HTML

HTML is used to create the structure of the EduGenie web interface.

### CSS

CSS is used for styling the interface, buttons, input areas, and result sections.

### JavaScript

JavaScript is used to handle user interactions and communicate with the backend APIs.

## 3. Backend Technology

### Python

Python is used as the main backend programming language.

### FastAPI

FastAPI is used to create the REST API and handle requests from the frontend.

### Uvicorn

Uvicorn is used as the ASGI server to run the FastAPI application.

## 4. AI Technology

### Google Gemini AI

Google Gemini is integrated to generate AI-powered educational responses.

It is used for:

- Question and Answer
- Topic Explanation
- Quiz Generation
- Text Summarization
- Personalized Learning Recommendations

## 5. Supporting Technologies

### Jinja2

Jinja2 is used for HTML templating.

### Pydantic

Pydantic is used for request validation and structured data handling.

### Environment Variables

Environment variables are used to securely store the Gemini API key.

## 6. Development Tools

- Visual Studio Code
- Git
- GitHub
- Web Browser
- Python Virtual Environment

## 7. Technology Stack Summary

| Layer | Technology |
|---|---|
| Frontend | HTML, CSS, JavaScript |
| Backend | Python, FastAPI |
| AI | Google Gemini |
| Web Server | Uvicorn |
| Template Engine | Jinja2 |
| Data Validation | Pydantic |
| Development IDE | Visual Studio Code |
| Version Control | Git and GitHub |
