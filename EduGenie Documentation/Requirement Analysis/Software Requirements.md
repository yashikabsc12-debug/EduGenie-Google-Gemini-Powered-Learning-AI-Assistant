# EduGenie – Software Requirements

## 1. Software Requirements Overview

The following software and development tools are required to develop and run EduGenie.

## 2. Operating System

EduGenie can be developed and executed on a supported operating system such as:

- Windows
- Linux
- macOS

## 3. Programming Language

- Python 3.10 or above
- HTML
- CSS
- JavaScript

## 4. Backend Framework

- FastAPI

FastAPI is used to develop the backend REST API.

## 5. AI Service

- Google Gemini API

Google Gemini is used to provide AI-powered educational responses.

## 6. Web Server

- Uvicorn

Uvicorn is used to run the FastAPI application locally.

## 7. Template Engine

- Jinja2

Jinja2 is used for HTML templating in the web application.

## 8. Data Validation

- Pydantic

Pydantic is used for request and data validation in the FastAPI application.

## 9. Development Environment

- Visual Studio Code
- Web Browser
- Command Prompt / Terminal

## 10. Package Management

Python dependencies are installed using `pip` and the project's `requirements.txt` file.

## 11. Software Requirement Summary

The EduGenie application uses Python, FastAPI, Google Gemini, HTML, CSS, JavaScript, Uvicorn, Jinja2, and Pydantic to provide the required learning features.
