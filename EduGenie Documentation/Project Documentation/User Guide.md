# EduGenie – User Guide

## 1. Introduction

EduGenie is an AI-powered learning assistant that helps students with different learning activities.

## 2. Opening EduGenie

Open the EduGenie application in a web browser using the local application URL.

## 3. Selecting a Learning Feature

Select the required learning feature from the available options:

- Explain
- QnA
- Quiz
- Summary
- Recommend Path

## 4. Question and Answer

1. Select **QnA**.
2. Enter your question.
3. Submit the request.
4. View the AI-generated answer.

## 5. Topic Explanation

1. Select **Explain**.
2. Enter the topic.
3. Select the required learning level.
4. Submit the request.
5. View the simplified explanation.

## 6. Quiz Generation

1. Select **Quiz**.
2. Enter the educational content.
3. Submit the request.
4. View the generated multiple-choice questions.

## 7. Text Summarization

1. Select **Summary**.
2. Enter the educational text.
3. Submit the request.
4. View the generated summary.

## 8. Learning Path

1. Select **Recommend Path**.
2. Enter the topic.
3. Provide the learning level.
4. Provide the learning goal.
5. Submit the request.
6. View the personalized learning recommendations.

## 9. Result Display

The generated response is displayed on the EduGenie interface after the request is processed.

## 10. User Benefits

EduGenie helps students:

- Understand difficult topics.
- Get answers to questions.
- Practice through quizzes.
- Quickly revise lengthy content.
- Follow a structured learning path.
