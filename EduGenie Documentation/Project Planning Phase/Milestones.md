# EduGenie – Project Milestones

## 1. Milestone Overview

The EduGenie project was divided into major milestones to organize the development process.

## 2. Milestone 1 – Project Planning

### Activities

- Identify the learning problem.
- Define project objectives.
- Identify target users.
- Define the proposed solution.
- Finalize the project scope.

### Expected Outcome

A clear project concept and development plan.

## 3. Milestone 2 – Backend Development

### Activities

- Set up the Python environment.
- Develop the FastAPI backend.
- Implement the AI learning modules.
- Create REST API endpoints.
- Connect the endpoints with the respective module logic.

### API Endpoints

- `/qa`
- `/explain`
- `/quiz`
- `/summarize`
- `/learn/recommendations`

### Expected Outcome

A functional backend API for the major EduGenie learning features.

## 4. Milestone 3 – Frontend Development

### Activities

- Develop the web interface.
- Create the task selection interface.
- Add text input areas.
- Add submit functionality.
- Apply CSS styling.
- Connect the frontend with the FastAPI backend.

### Expected Outcome

A functional web interface connected to the backend.

## 5. Milestone 4 – Deployment and Testing

### Activities

- Run the application locally using Uvicorn.
- Test Question and Answer.
- Test Topic Explanation.
- Test Quiz Generation.
- Test Text Summarization.
- Test Personalized Learning Recommendations.
- Fix identified issues.

### Expected Outcome

A working EduGenie application ready for demonstration.

## 6. Milestone Summary

| Milestone | Main Activity | Outcome |
|---|---|---|
| Milestone 1 | Project Planning | Project scope and objectives |
| Milestone 2 | Backend Development | FastAPI backend and APIs |
| Milestone 3 | Frontend Development | Interactive web interface |
| Milestone 4 | Deployment and Testing | Tested working application |
