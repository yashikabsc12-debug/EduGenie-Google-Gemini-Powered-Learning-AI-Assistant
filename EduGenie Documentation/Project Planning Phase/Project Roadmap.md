# EduGenie – Project Roadmap

## 1. Project Overview

EduGenie is an AI-powered learning assistant designed to help students with Question and Answer, Topic Explanation, Quiz Generation, Text Summarization, and Personalized Learning Recommendations.

## 2. Project Roadmap

The development of EduGenie was planned through the following major stages:

### Stage 1 – Project Ideation

- Identify the problem faced by students.
- Define the purpose of EduGenie.
- Identify the target users.
- Define the major learning features.

### Stage 2 – Requirement Analysis

- Identify functional requirements.
- Identify non-functional requirements.
- Define hardware and software requirements.
- Select the required technologies.

### Stage 3 – System Design

- Design the system architecture.
- Design the major application modules.
- Define the data flow.
- Design the API endpoints.
- Plan the user interface.

### Stage 4 – Backend Development

- Set up the Python environment.
- Develop the FastAPI backend.
- Create API endpoints.
- Develop the learning modules.
- Integrate the AI service.

### Stage 5 – Frontend Development

- Develop the HTML interface.
- Add CSS styling.
- Implement JavaScript functionality.
- Connect the frontend with the backend.
- Display generated results.

### Stage 6 – AI Integration

- Integrate Google Gemini AI.
- Develop prompts for different learning tasks.
- Generate answers, explanations, quizzes, summaries, and learning recommendations.

### Stage 7 – Testing

- Perform unit testing.
- Perform API testing.
- Perform integration testing.
- Perform UI testing.
- Fix identified issues.

### Stage 8 – Deployment and Demonstration

- Run the application locally using Uvicorn.
- Verify all major features.
- Capture application screenshots.
- Prepare project documentation and demonstration materials.
