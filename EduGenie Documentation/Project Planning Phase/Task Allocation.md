# EduGenie – Task Allocation

## 1. Task Allocation Overview

The EduGenie project activities were organized into different development tasks covering planning, design, development, AI integration, testing, and documentation.

## 2. Project Planning Tasks

- Define the problem statement.
- Identify the target users.
- Define project objectives.
- Analyze the existing system.
- Define the proposed solution.

## 3. Requirement Analysis Tasks

- Identify functional requirements.
- Identify non-functional requirements.
- Identify hardware requirements.
- Identify software requirements.
- Finalize the technology stack.

## 4. Design Tasks

- Design system architecture.
- Design application modules.
- Prepare data flow diagrams.
- Prepare flowcharts.
- Design API structure.
- Design the user interface.

## 5. Backend Development Tasks

- Set up the Python environment.
- Develop the FastAPI application.
- Create request and response models.
- Implement API endpoints.
- Implement error handling.

## 6. AI Integration Tasks

- Configure Google Gemini API.
- Develop AI service integration.
- Create prompts for learning tasks.
- Implement Question and Answer.
- Implement Topic Explanation.
- Implement Quiz Generation.
- Implement Text Summarization.
- Implement Learning Path Recommendations.

## 7. Frontend Development Tasks

- Develop HTML interface.
- Develop CSS styling.
- Implement JavaScript functionality.
- Create task selection.
- Implement form submission.
- Display AI-generated results.

## 8. Testing Tasks

- Perform unit testing.
- Perform API testing.
- Perform integration testing.
- Perform UI testing.
- Prepare test cases.
- Identify and fix bugs.

## 9. Documentation Tasks

- Prepare project report.
- Prepare installation guide.
- Prepare user guide.
- Prepare API documentation.
- Prepare security documentation.
- Prepare future enhancement documentation.

## 10. Demonstration Tasks

- Capture application screenshots.
- Demonstrate major learning features.
- Prepare presentation materials.
- Prepare project demonstration video.
