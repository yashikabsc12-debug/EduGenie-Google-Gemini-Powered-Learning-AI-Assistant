# EduGenie – UI Testing

## 1. UI Testing Overview

UI testing was performed to verify the functionality and usability of the EduGenie web interface.

## 2. UI Components Tested

- Task selection
- Text input area
- Submit button
- Result display area
- Responsive interface

## 3. Task Selection

The task dropdown was tested with the following options:

- Explain
- QnA
- Quiz
- Summary
- Recommend Path

## 4. User Input

The input area was tested by entering questions, topics, and educational content according to the selected task.

## 5. Submit Functionality

The submit button was tested to verify that the entered information is sent to the FastAPI backend.

## 6. Result Display

The generated AI response was checked to verify that it appears correctly below the input area.

## 7. Result

The main user interface components and interaction flow were tested successfully.
