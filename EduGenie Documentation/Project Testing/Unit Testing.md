# EduGenie – Unit Testing

## 1. Unit Testing Overview

Unit testing was performed to verify individual backend functions and application components.

## 2. Components Tested

- Homepage
- Health Check
- API Information
- Request Validation

## 3. Homepage Test

The homepage was tested to verify that the EduGenie application loads successfully.

## 4. Health Check Test

The health endpoint was tested to verify that the backend application is running correctly.

## 5. API Information Test

The API information endpoint was tested to verify that the available EduGenie endpoints are returned correctly.

## 6. Validation Test

Invalid or incomplete requests were tested to verify that appropriate validation errors are returned.

## 7. Result

The individual backend components were tested for expected responses and validation behaviour.
