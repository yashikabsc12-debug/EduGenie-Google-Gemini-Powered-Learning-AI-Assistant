# EduGenie – Testing Strategy

## 1. Testing Overview

Testing was performed to verify the functionality of the EduGenie application and its major learning features.

## 2. Testing Objectives

- Verify that the application runs successfully.
- Verify the frontend and backend integration.
- Verify the API endpoints.
- Verify the AI-powered learning features.
- Identify and resolve errors.

## 3. Features Tested

- Question and Answer
- Topic Explanation
- Quiz Generation
- Text Summarization
- Personalized Learning Path

## 4. Testing Approach

The following testing methods were used:

- Unit Testing
- API Testing
- Integration Testing
- UI Testing
- Functional Testing

## 5. Testing Process

1. Run the EduGenie application.
2. Open the application in a browser.
3. Select a learning feature.
4. Enter the required input.
5. Submit the request.
6. Verify the generated response.
7. Check for errors.
8. Record the test result.

## 6. Testing Result

The major components and learning features of EduGenie were tested to verify their functionality.
