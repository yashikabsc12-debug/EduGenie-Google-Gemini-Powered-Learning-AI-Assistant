# EduGenie – API Testing

## 1. API Testing Overview

API testing was performed to verify that the FastAPI endpoints receive requests and return appropriate responses.

## 2. Endpoints Tested

- `POST /qa`
- `POST /explain`
- `POST /quiz`
- `POST /summarize`
- `POST /learn/recommendations`

## 3. Question and Answer API

The `/qa` endpoint was tested by submitting questions and verifying the generated answers.

## 4. Explanation API

The `/explain` endpoint was tested by submitting topics and learning levels and verifying the generated explanations.

## 5. Quiz API

The `/quiz` endpoint was tested by providing educational content and verifying the generated quiz.

## 6. Summarization API

The `/summarize` endpoint was tested by providing educational text and verifying the generated summary.

## 7. Learning Path API

The `/learn/recommendations` endpoint was tested by providing a topic, learning level, and learning goal and verifying the generated recommendations.

## 8. Result

The API endpoints were tested according to their respective learning functions.
