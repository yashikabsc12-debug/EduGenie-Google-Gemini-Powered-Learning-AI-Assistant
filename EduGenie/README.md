# EduGenie

## Google Gemini Powered Learning Assistant

EduGenie is an AI-powered educational assistant designed to help students learn more effectively.

It provides:

- Question and Answer
- Topic Explanation
- Quiz Generation
- Text Summarization
- Personalized Learning Paths

## Technology Stack

### Frontend
- HTML
- CSS
- JavaScript

### Backend
- Python
- FastAPI
- Uvicorn

### AI
- Google Gemini
- Google GenAI Python SDK

### Validation
- Pydantic

## Requirements

- Python 3.10 or higher
- Google Gemini API key
- Internet connection
- Visual Studio Code
